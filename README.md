# vatanilabs.com

The Vatani Labs website: plain HTML and CSS, no build step needed to view it.

- `index.html`: home (hero, app showcase, principles, contact)
- `petrogram/`: PetroGram page, privacy policy and terms of use (7 languages)
- `assets/`: stylesheet, hero animation, images
- `CNAME`: the custom domain for GitHub Pages

Preview locally: `python3 -m http.server 8765` in this folder, then open
http://localhost:8765.
